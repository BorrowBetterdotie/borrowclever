BorrowClever API

Authenticated JSON access to the same loan and credit card comparison data published on this site.

Base URL and authentication

All requests require an API key, sent as a bearer token:

Authorization: Bearer bc_live_your_key_here

Keys are issued manually. Email hello@borrowclever.ie to request one.

Endpoints

meta.generated in every response reflects when this dataset was last built and deployed — not the current request time.

GET https://borrowclever.ie/api/v1/loans — every personal loan currently on the loans comparison page.

Example response:

{
  "meta": {
    "generated": "2026-08-12T10:00:00.000Z",
    "last_full_review": "2026-07-22",
    "source": "https://borrowclever.ie/loans.html"
  },
  "data": [
    {
      "id": "boi-sbci-green",
      "lender": "Bank of Ireland",
      "product": "SBCI Home Energy Upgrade",
      "apr": 2.95,
      "rateType": "Variable",
      "green": true,
      "seai": true,
      "notes": "75% of loan on qualifying energy works",
      "badgeCheapestOverall": true
    }
  ]
}

Each object in data has:

  • id (string) — stable identifier for this loan product
  • lender (string) — e.g. "Bank of Ireland"
  • product (string) — product name, e.g. "SBCI Home Energy Upgrade"
  • apr (number) — representative/nominal APR, e.g. 2.95
  • rateType (string) — "Variable" or "Fixed"
  • green (boolean, optional) — present and true only on green/energy-upgrade loans
  • seai (boolean, optional) — present and true only on loans that require an SEAI grant
  • creditUnion (boolean, optional) — present and true only on credit union loans
  • typeNote (string, optional) — a short qualifier shown alongside some loans, e.g. "3-hour decision", "No early repayment fee"
  • notes (string, optional) — free-text notes/caveats (not present on every loan)
  • badgeCheapestOverall (boolean, optional) — present and true only on the single cheapest loan overall
  • badgeBestStandard (boolean, optional) — present and true only on the single best non-green, non-credit-union loan

GET https://borrowclever.ie/api/v1/cards — every credit card currently on the cards comparison page.

Example response:

{
  "meta": {
    "generated": "2026-08-12T10:00:00.000Z",
    "last_full_review": "2026-07-22",
    "source": "https://borrowclever.ie/cards.html"
  },
  "data": [
    {
      "id": "aib-click",
      "lender": "AIB",
      "product": "Click",
      "network": "Visa",
      "purchaseRate": "9.11%",
      "apr": 13.8,
      "balanceTransferOffer": null,
      "annualFee": 0,
      "notes": "Online-only application. No 0% intro — but its 13.8% standard APR is Ireland's lowest, so it can work out cheaper than cards that revert to ~22.9% once a 0% period ends.",
      "badgeCheapestOverall": true
    }
  ]
}

Each object in data has:

  • id (string) — stable identifier for this card product
  • lender (string) — e.g. "AIB"
  • product (string) — product name, e.g. "Click"
  • network (string) — e.g. "Visa", "Mastercard"
  • purchaseRate (string or null) — nominal purchase rate as displayed, e.g. "9.11%"
  • apr (number) — representative APR, e.g. 13.8
  • balanceTransferOffer (string or null) — free-text description of any balance-transfer intro offer
  • annualFee (number) — annual card fee in euro, 0 if none (excludes the €30 government stamp duty, which applies to all cards)
  • notes (string or null) — free-text notes
  • badgeCheapestOverall (boolean, optional) — present and true only on the single lowest-APR card

Rate limits

Limits are per key, per UTC day:

  • Free — 100 requests/day
  • Paid — 10,000 requests/day

Exceeding your limit returns 429 with a Retry-After header (seconds until the next UTC midnight).

Errors

Errors are returned as { "error": { "code": "...", "message": "..." } }:

  • 401 unauthorized — missing or unknown key
  • 401 revoked — key has been revoked
  • 429 rate_limited — daily limit reached

This API is separate from BorrowClever's comparison tables — the ranking methodology described on how we make money applies to the site, not to API access itself.
